# Contributing

This repo is a plain-text skill, a method with no code. Small, focused fixes are welcome.

## Before you start

- Found a mistake or have a question? Open an [issue](https://github.com/nickspiz/niche-trends-30d/issues/new/choose) or start a [discussion](https://github.com/nickspiz/niche-trends-30d/discussions).
- Know a better scoring weight or a filter that catches a real problem? Say what you saw, on which network and in which niche. Numbers from a real run help most.
- Planning something bigger than a few dozen lines, such as a new network? Open an issue first.

## Checking your change

There is no code to test. Read the files you changed. Check that the front matter has `name` and `description`, that the folder name matches `name`, and that every link works.

## Rules for the text

- Examples use made-up products. No real brands, people or numbers.
- No em dashes. Use a hyphen, a comma, a colon or two sentences.
- Do not add scrapers or ways around a platform's login or limits.

## Pull requests

- One change per pull request.
- Say what changed and why, in plain English.
- Update the README if the change is visible to users.

By contributing you agree that your work is released under the MIT license.
